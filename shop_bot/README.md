# Магазин цифровых товаров с автовыдачей

Telegram-бот-магазин: каталог, корзина, оплата звёздами Telegram (⭐) и моментальная
выдача товара после оплаты — 24/7, без участия продавца. Пример: магазин игровых
ключей и гайдов.

## Что умеет

**Покупатель**
- Каталог по категориям, карточка товара с описанием, ценой и остатком
- Корзина: добавить, изменить количество, очистить
- Оплата звёздами Telegram прямо в чате — картой, Apple Pay, Google Pay
- Товар приходит сразу после оплаты: уникальный код или ссылка
- «📦 Мои покупки» — получить купленное повторно в любой момент

**Продавец**
- Уведомление о каждой продаже
- Предупреждение, когда заканчиваются коды
- `/admin` — продажи за сегодня и всего, остатки на складе
- Пополнение склада: прислать боту коды списком, каждый с новой строки
- `/refund 12` — вернуть звёзды по заказу

**Надёжность**
- Один код никогда не достанется двум покупателям (выдача в одной транзакции)
- Перед списанием бот проверяет, что товар есть; если он закончился в момент оплаты —
  звёзды возвращаются автоматически

## Типы товаров

В `config.py` → `PRODUCTS`:
- `codes` — уникальный код каждому (ключи, промокоды, доступы). Коды загружаются через `/admin`
- `text` — одинаковое содержимое всем (ссылка на файл, курс, гайд)

## Почему звёзды Telegram

Для цифровых товаров в ботах Telegram требует оплату звёздами. Плюсы: не нужны ИП,
договор с банком и платёжный провайдер, покупатель платит привычной картой.
Заработанные звёзды продавец выводит через Fragment или тратит на рекламу в Telegram.
Для физических товаров и услуг можно подключить ЮKassa — это отдельная доработка.

## Запуск

1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN`
3. `python bot.py`
4. `/myid` → впишите ID в `ADMIN_IDS` → перезапуск

Для демо: `DEMO_PAYMENTS=1` — появится кнопка «Тестовая оплата», покупку можно пройти бесплатно.

## Структура

| Файл | Что внутри |
|---|---|
| `config.py` | тексты, категории и товары |
| `handlers/user.py` | каталог, корзина, оплата, выдача |
| `handlers/admin.py` | статистика, склад, возвраты |
| `keyboards.py` | кнопки |
| `db.py` | корзины, склад, заказы (SQLite) |

Стек: Python, aiogram 3, Telegram Payments (Stars), SQLite.
