# Бот для канала: автопостинг и модерация чата

Помощник админа Telegram-канала. Публикует посты по расписанию и держит порядок в чате:
удаляет ссылки, рекламу и спам, предупреждает и мьютит нарушителей.

## Что умеет

**Отложенный постинг**
- Админ присылает боту пост — текст, фото, видео, файл, опрос — как он должен выглядеть в канале
- Выбирает время: «Сейчас», «Через час», «Сегодня в 19:00», «Завтра в 10:00» или своё
  (`18:30`, `27.10 18:30`, `завтра 10:00`, `через 2 часа`)
- В нужное время пост появляется в канале с сохранённым форматированием
- `/queue` — очередь постов с кнопками отмены
- После публикации бот присылает ссылку на пост

**Модерация чата**
- Удаляет ссылки и сообщения со стоп-словами от обычных участников
- Нейросеть распознаёт рекламу и спам, даже без ссылок и стоп-слов (если подключена)
- Предупреждения: 1/3, 2/3, на третьем — мут на час (настраивается)
- Приветствует новых участников и убирает служебные «вступил(а) в группу»
- Админов чата и посты канала не трогает
- `/admin` — статистика: посты, удалённые нарушения, муты

## Подключение

1. **Канал:** добавьте бота в администраторы канала с правом «Публикация сообщений».
   Впишите `CHANNEL_ID=@имя_канала` в `.env`.
2. **Чат:** добавьте бота в группу (или чат обсуждения канала) администратором с правами
   «Удаление сообщений» и «Блокировка пользователей».
3. **Нейросеть (по желанию):** ключ Groq — бесплатно на https://console.groq.com — в `AI_API_KEY`.

## Запуск

1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и `CHANNEL_ID`
3. `python bot.py`
4. `/myid` → впишите ID в `ADMIN_IDS` → перезапуск

## Настройка правил

В `config.py`: `STOP_WORDS`, `DELETE_LINKS`, `MAX_WARNINGS`, `MUTE_HOURS`,
`WELCOME_TEXT`, `DELETE_JOIN_MESSAGES`, `AI_MODERATION`.

## Структура

| Файл | Что внутри |
|---|---|
| `config.py` | канал, правила модерации, стоп-слова |
| `handlers/admin.py` | приём постов и выбор времени |
| `handlers/group.py` | модерация чата |
| `publisher.py` | публикация в канал по расписанию |
| `timeparse.py` | разбор времени («завтра 10:00», «через 2 часа») |
| `ai.py` | проверка на спам нейросетью |
| `db.py` | очередь постов, предупреждения, журнал (SQLite) |

Стек: Python, aiogram 3, SQLite, OpenAI-совместимый API.
