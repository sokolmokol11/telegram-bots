# Бот приёма заявок с калькулятором и Google Таблицей

Telegram-бот, который 24/7 считает стоимость услуги, собирает заявки
и складывает их в Google Таблицу. Пример настроен под клининг,
но анкета и калькулятор меняются в `config.py` за 10 минут.

## Что умеет

**Клиент**
- 🧮 Калькулятор: выбрал услугу, ввёл площадь — сразу видит примерную цену
- 📝 Заявка по шагам: услуга, площадь, адрес, удобное время, имя, телефон, комментарий
- Из калькулятора в заявку в один клик: услуга и площадь подставляются сами
- Телефон — кнопкой «Отправить мой номер» или текстом в любом формате
- ❓ Частые вопросы и 📍 контакты
- Получает сообщение, когда менеджер взял заявку в работу

**Менеджер**
- Мгновенное уведомление о каждой заявке с кнопками статуса: «В работе», «Выполнена», «Отказ»
- Все заявки автоматически попадают в Google Таблицу, статус там тоже обновляется
- `/admin`: статистика (всего, сегодня, по статусам), последние 10 заявок
- Выгрузка всех заявок в CSV, который открывается в Excel

Если Google Таблица не настроена или Google недоступен — бот продолжает работать:
заявки сохраняются в базе и приходят менеджеру.

## Запуск

1. Python 3.10+, затем `pip install -r requirements.txt`
2. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен
3. Скопируйте `.env.example` в `.env`, впишите токен
4. `python bot.py`
5. Напишите боту `/myid`, впишите ID в `ADMIN_IDS` и перезапустите бота

## Google Таблица (необязательно)

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/), создайте проект.
2. Включите **Google Sheets API** и **Google Drive API** (раздел «APIs & Services → Library»).
3. «APIs & Services → Credentials → Create credentials → Service account». Создайте аккаунт,
   откройте его → вкладка «Keys» → «Add key → JSON». Скачанный файл положите рядом с ботом
   под именем `credentials.json`.
4. Создайте Google Таблицу и нажмите «Поделиться»: добавьте email сервисного аккаунта
   (он есть в `credentials.json`, поле `client_email`) с правом **Редактор**.
5. Скопируйте ID таблицы из ссылки (`docs.google.com/spreadsheets/d/<ВОТ_ЭТО>/edit`)
   в `GOOGLE_SHEET_ID` в `.env` и перезапустите бота.

Заголовки столбцов бот создаст сам.

## Как переделать под другой бизнес

Всё в `config.py`:
- `WELCOME_TEXT`, `CONTACTS_TEXT`, `DONE_TEXT` — тексты
- `CALC_SERVICES` — услуги калькулятора: цена за м² и минимальная стоимость
- `FORM` — вопросы анкеты. Типы: `choice` (кнопки), `text`, `number`, `phone`;
  `optional: True` — можно пропустить. Добавили вопрос — он сам появится в анкете,
  в уведомлении менеджеру, в Google Таблице и в CSV
- `FAQ` — частые вопросы
- `STATUSES`, `CLIENT_STATUS_TEXT` — статусы и что писать клиенту при их смене

## Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | запуск |
| `config.py` | все настройки бизнеса |
| `handlers/user.py` | меню, калькулятор, FAQ, анкета |
| `handlers/admin.py` | статусы, статистика, выгрузка |
| `keyboards.py` | кнопки |
| `db.py` | база SQLite (`leads.db`) |
| `sheets.py` | запись в Google Таблицу |

Стек: Python, aiogram 3, SQLite, gspread.
