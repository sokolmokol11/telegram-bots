# ИИ-консультант для бизнеса

Telegram-бот, который 24/7 отвечает клиентам как живой консультант — по информации
о вашей компании. Если вопрос сложный или клиент хочет человека, бот подключает менеджера,
и тот отвечает прямо в чате бота. Пример настроен под автосервис.

## Что умеет

**Клиент**
- Пишет вопрос обычным текстом — получает ответ за пару секунд, в любое время
- Бот помнит контекст разговора (последние 8 реплик)
- «👤 Позвать менеджера» — дальше он переписывается с живым человеком в этом же чате
- «🔄 Новый диалог» — начать заново

**Менеджер**
- Получает вопрос клиента вместе с последними репликами диалога с ботом
- Отвечает свайпом «Ответить» — бот доставляет ответ клиенту (текст, фото, файлы)
- `/admin` — статистика: сколько ответов дал ИИ, сколько вопросов передано людям

**Защита**
- ИИ отвечает только по базе знаний и не выдумывает цены
- Лимит вопросов на человека в день (по умолчанию 30) — бесплатный тариф нейросети не «съедят»
- Если нейросеть недоступна — бот не молчит, а предлагает связаться с менеджером

## База знаний

Всё, что знает бот, лежит в файле `knowledge.md` — обычный текст: услуги, цены,
адрес, часы, гарантия, частые вопросы. Изменили файл — бот сразу отвечает по-новому,
перезапуск не нужен.

## Нейросеть

По умолчанию — **Groq**: бесплатный тариф без карты, модель llama-3.3-70b.
1. Зарегистрируйтесь на https://console.groq.com и создайте ключ (API Keys)
2. Впишите его в `.env` → `AI_API_KEY=`

Подходит любая нейросеть с OpenAI-совместимым API (DeepSeek, OpenRouter, OpenAI…):
меняются только `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`. Примеры — в `.env.example`.

Если сервер в России и нейросеть недоступна напрямую, бот ходит к ней через тот же
прокси, что и к Telegram (`AI_USE_PROXY=1`).

## Запуск

1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и `AI_API_KEY`
3. `python bot.py`
4. `/myid` → впишите ID в `ADMIN_IDS` → перезапуск

## Структура

| Файл | Что внутри |
|---|---|
| `knowledge.md` | база знаний — главное, что меняется под заказчика |
| `config.py` | тексты, настройки нейросети, инструкция для ИИ |
| `ai.py` | запрос к нейросети |
| `handlers/user.py` | ответы ИИ, режим «менеджер» |
| `handlers/admin.py` | ответы менеджера клиентам, статистика |
| `db.py` | история диалогов, статистика (SQLite) |

Стек: Python, aiogram 3, OpenAI-совместимый API, SQLite.
