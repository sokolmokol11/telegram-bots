# Бот онлайн-записи (маникюр / репетитор / любые услуги)

Telegram-бот, который принимает записи клиентов 24/7 и присылает их мастеру.

## Что умеет

**Клиент**
- Выбирает услугу → день → свободное время (показываются только реально свободные окна с учётом длительности услуги)
- Оставляет имя и телефон (кнопкой «Отправить мой номер» или текстом); постоянных клиентов бот узнаёт и не спрашивает снова
- Видит свои записи и может отменить их
- Получает напоминание за 24 часа до визита

**Мастер (команда /admin)**
- Мгновенное уведомление о каждой новой записи и отмене
- Расписание на сегодня, завтра и 7 дней
- Отмена записи в один клик (клиенту приходит сообщение)
- Закрытие любых дней как выходных

**Надёжность:** два клиента не смогут записаться на одно время, даже нажав «Подтвердить» одновременно.

## Запуск

1. Установите Python 3.10+.
2. В папке бота выполните:
   ```
   pip install -r requirements.txt
   ```
3. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
4. Скопируйте `.env.example` в `.env` и впишите токен.
5. Запустите:
   ```
   python bot.py
   ```
6. Напишите боту `/myid`, впишите полученный ID в `ADMIN_IDS` в `.env` и перезапустите бота. Теперь вам доступна `/admin` и приходят уведомления.

## Как переделать под другой бизнес

Всё настраивается в `config.py`, код трогать не нужно:
- `BUSINESS_NAME`, `WELCOME_TEXT`, `CONTACTS_TEXT` — тексты
- `SERVICES` — услуги, цены и длительность
- `WORK_START`, `WORK_END`, `WORK_WEEKDAYS` — график
- `SLOT_STEP_MINUTES`, `BOOKING_DAYS_AHEAD`, `MIN_HOURS_BEFORE`, `REMIND_HOURS_BEFORE`

Пример для репетитора:
```python
SERVICES = [
    {"id": "trial", "name": "Пробное занятие", "price": 0, "minutes": 30},
    {"id": "ege", "name": "Подготовка к ЕГЭ (математика)", "price": 1500, "minutes": 60},
    {"id": "oge", "name": "Подготовка к ОГЭ", "price": 1200, "minutes": 60},
]
SLOT_STEP_MINUTES = 60
```
Эмодзи 💅 в текстах кнопок тоже стоит заменить.

## Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | запуск бота |
| `config.py` | все настройки бизнеса |
| `handlers/user.py` | меню и пошаговая запись клиента |
| `handlers/admin.py` | панель мастера |
| `keyboards.py` | все кнопки |
| `schedule.py` | расчёт свободных окон |
| `db.py` | база данных SQLite (`bookings.db`) |
| `reminders.py` | напоминания клиентам |

Стек: Python, aiogram 3, SQLite.
